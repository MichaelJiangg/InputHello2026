# InputHello — 看得见的 macOS 输入法切换

> 切换输入法时，在屏幕中央清楚显示「从哪来，到哪去」。

InputHello 是一款轻量的 macOS 菜单栏工具。它不会改变输入法切换方式，只为原来的操作补上一层清晰、及时的视觉反馈。

不用盯着菜单栏，也不用先敲一个字确认当前输入法。

- **切换结果一眼可见**：同时显示上一个与当前输入法
- **连续切换逐步跟上**：按住修饰键循环切换时，每按一次都会更新
- **安静地留在后台**：不占 Dock、不抢焦点，提示层点击穿透

[下载最新版本](../../releases/latest)

## 为什么需要 InputHello

macOS 26 的输入法切换反馈比较弱。

当你安装了多个输入法，按住修饰键连续切换时，很难在不转移视线的情况下确认当前选中了哪一个。

InputHello 只解决这一件事：

> **让每一次输入法切换都有明确反馈。**

切换发生时，屏幕中央会显示：

- 上一行：切换前的输入法，以灰色显示
- 下一行：当前输入法，以白色高亮显示

提示会在 1.2 秒后自动淡出。无论安装了多少个输入法，始终只显示你此刻真正关心的两个状态。

提示层不接收鼠标事件，不会挡住当前操作，并可显示在常规全屏应用之上。

## 快速开始

1. 前往 [Releases](../../releases/latest)
2. 下载最新版本的 `.dmg` 安装包
3. 将 InputHello 拖入「应用程序」
4. 双击启动

启动后，InputHello 会常驻菜单栏：

- 不占用 Dock
- 不进入 `Cmd-Tab` 应用列表
- 不影响当前窗口焦点
- 只在切换输入法时显示提示

发布包已经过 Developer ID 签名和 Apple 公证，公证票据已附加到 App 与 DMG。正常情况下，Gatekeeper 可以直接完成验证，无需绕过 macOS 安全设置。

### 菜单栏常驻

日常运行时，InputHello 是一个纯菜单栏工具。

首次启动或尚未完成权限设置时，App 会暂时以普通应用形态显示引导窗口。关闭窗口后，它会自动收回菜单栏。

如果 InputHello 已经在后台运行，再次双击应用图标也可以重新打开窗口。

## 权限说明

### 一定要授权吗？

**不一定。**

| 状态 | 使用效果 |
| --- | --- |
| 未授权 | 松开修饰键后显示最终结果；单次切换不受影响 |
| 已授权 | 按住修饰键连续切换时，每一步都能及时显示 |

如果你通常只进行“按一下就松开”的单次切换，即使不授权，InputHello 也可以正常使用。

---

### 为什么需要权限？

为了在按住修饰键期间跟进每一次切换，InputHello 需要监听系统级输入法切换快捷键。

事件监听使用 `CGEventTap` 的 `.listenOnly` 模式：

- 只接收事件副本
- 不修改或拦截按键
- 不注入键盘事件
- 不保存或上传输入内容
- 非输入法切换事件会被立即忽略

---

### 授权流程

InputHello 不会在你尚不了解用途时直接请求权限。

首次启动时，App 会先展示用途说明。只有你主动选择授权后，才会引导你前往对应的系统设置页面。

点击「打开系统设置…」后，系统设置窗口下方会出现两步引导：

1. 将 InputHello 添加到权限列表；如果已经存在，会自动跳过
2. 打开 InputHello 右侧的权限开关

权限开启后，状态会立即更新，并在短暂停留后自动收起引导。

如果首次没有授权，之后仍然可以随时前往「系统设置 → 隐私与安全性」手动开启。

## 菜单栏功能

| 菜单项 | 作用 |
| --- | --- |
| 关于应用 | 查看版本及当前生效的输入法切换快捷键 |
| 预览效果 | 使用当前输入法演示一次提示效果 |
| 用户反馈 | 使用默认浏览器打开反馈渠道 |
| 开机启动 | 通过 `SMAppService` 注册为登录项 |
| 退出 InputHello | 完全退出应用 |

## 系统要求

当前发布版本支持：

**macOS 26.4 或更高版本**

更早版本尚未完成兼容性测试，当前暂不承诺支持。

> 对开发者：降低 `MACOSX_DEPLOYMENT_TARGET` 后仍需重新构建，并检查 API 可用性、依赖配置及实际运行表现。修改构建目标本身不等于已经完成兼容。

---

## 隐私

InputHello 不包含统计或遥测功能，也不会在后台上传数据。

App 会接收系统级按键事件，但只比对：

- 按键的 `keyCode`
- 当前修饰键状态
- 是否与输入法切换快捷键匹配

InputHello 不读取、保存或上传字符内容。只有你主动点击「用户反馈」时，系统才会使用默认浏览器打开反馈页面。

---

## 反馈问题

如果遇到切换顺序不准确、快捷键无法识别或提示未出现，请在反馈中附上：

- macOS 版本
- InputHello 版本
- 已安装的输入法
- 当前设置的切换快捷键
- 问题出现时的操作步骤

必要时也可以附上：

```text
~/Library/Logs/InputHello.log
```
